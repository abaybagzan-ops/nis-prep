# Отбасылық ағылшын — семейное приложение для английского

Самостоятельный проект. Не связан с подготовкой к НИШ.

Интерфейс на казахском, учебный материал на английском. Первая версия охватывает только слова, грамматику и чтение коротких текстов.

## Как запустить

Сборка, сервер и интернет не нужны.

- **Самый простой способ:** открыть `index.html` двойным щелчком в браузере (Chrome, Edge, Firefox, Safari).
- **Через локальный сервер** (удобно, чтобы открыть с телефона в той же сети):

  ```bash
  cd family-english-app
  python3 -m http.server 8000
  ```

  Затем открыть `http://localhost:8000`.

Прогресс хранится в `localStorage` браузера под ключом `familyEnglishApp.v1`. Он привязан к устройству и браузеру и на другое устройство не переносится.

## Структура

```
index.html                 оболочка, порядок подключения скриптов

js/content/stages.js       ступени, интересы, НАСТРОЙКИ ПИЛОТА (FEA.settings)
js/content/helpers.js      конструкторы заданий: choice / typed / order / match / word

js/content/lessons-stage0..3.js  уроки по ступеням

js/engine.js               логика: сборка урока, проверка, повторение, рекомендации
js/ui.js                   создание элементов, окно подтверждения
js/app.js                  экраны
tools/validate-content.js  проверка учебных данных (node)
```

## Учебная модель

- **4 внутренние ступени:** «Нөлден бастау», «Бастауыш», «Негізгі», «Орта және одан жоғары». Обозначения A0–B2 в `cefrHint` — только предварительный ориентир, а не сертификация.
- **У каждого навыка своя ступень.** На каждую ступень приходится 3 урока: по одному на слова, грамматику и чтение. Всего 12 уроков.
- **Урок строится так:**
  1. разминка (вспоминание);
  2. 1–2 повтора, у которых наступил срок;
  3. цель, объяснение, примеры, новые слова;
  4. задания от узнавания к вспоминанию и применению;
  5. текст и задания по нему.

  Основных заданий 4–6.
- **Интерес** меняет только текст, задания по тексту и тематические слова. Тематических слов не больше половины новых слов урока. Порядок целей и ступень от интереса не зависят. «Басқа қызығушылық» пока использует тексты о повседневной жизни.
- **Повторение:** интервалы 1 → 3 → 7 → 14 → 30 дней. Ошибка возвращает вопрос на 1 день. В уроке не больше 2 повторов, в отдельной сессии — до 6.
- **Ступень автоматически не меняется.** Приложение только предлагает «Келесі сатыны байқап көру» («Попробовать следующую ступень»), а решает ученик. Предложение появляется, если урок пройден с точностью от 80% и после него по этому навыку было не меньше 2 верных повторений.
- Все числа в `FEA.settings` — **настройки пробного запуска, а не нормы из исследований.**

## Как добавить урок

1. Добавить объект в нужный `lessons-stageN.js` через `FEA.lessons.push({...})`. Поля:
   - `id`, `stage`, `skill`, `title`, `goal`, `explain[]`, `examples[]`;
   - `words[]` — общеупотребительные слова;
   - `warmup` — задание на разминку;
   - `tasks[]` — основные задания;
   - `contexts` — для `usa`, `mystery`, `sport`, `travel`, `everyday`: `themeWords`, `text {title, lines, glossary}`, `tasks`;
   - `review[]` с уникальными `id`;
   - `editorNotes[]` — пометки для редактора, ученику они не показываются.
2. Если на ступени и навыке появляется больше одного урока, нужно дописать `lessonFor` в `engine.js`: сейчас там соответствие «одна ступень — один урок навыка».
3. Запустить проверку:

   ```bash
   node tools/validate-content.js --notes
   ```

## Что требует проверки специалистом

Список выводится командой `node tools/validate-content.js --notes`. Главное:

- **все казахские объяснения**, особенно сопоставления «-мын ↔ am», «...ып жатқан еді ↔ was/were + -ing», «қарамастан ↔ although/despite», «шаршадым ↔ I'm tired»;
- переводы gate, clue, barely, afford, haunted, tip и фразовых глаголов;
- примерное чтение кириллицей на ступенях 0–1 («хэлоу», «сэнк ю»): это грубое приближение, методист должен решить, оставлять ли его;
- естественность английских текстов и соответствие текстов ступеням.

Материалы написаны с нуля для этого приложения. Преподаватель, носитель английского и специалист по казахскому их не проверяли.
