# NIS-ке дайындық

Учебная платформа для подготовки ученика 6 класса к поступлению в NIS: уроки, диагностика, полный пробный тест в формате NIS (по буклету ЦПИ NIS 2026–2027 и объявлению на 2027–2028), журнал ошибок и недельный план. Интерфейс на казахском и русском.

Задания авторские, это не официальные задания NIS. Тренировочный результат не является официальным баллом и не предсказывает поступление.

- `index.html` — приложение (работает офлайн после первого открытия).
- `source/` — исходники; сборка: `node source/tools/build.js` (из исходной структуры проекта), проверка банка: `node source/tools/validate.js`.

Прогресс хранится только в браузере устройства ученика.
